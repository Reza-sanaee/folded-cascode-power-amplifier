# Folded-Cascode Amplifier Redesign with Class-B Output

An LTspice circuit study redesigns an amplifier input stage using a folded-cascode arrangement and transistor current mirrors while retaining a class-B output stage. It examines gain, output swing, bias power, and distortion. The reported redesign improves swing/distortion relative to the initial circuit but fails the assignment's power and THD targets.

## Technical highlights

- Designed and simulated a folded-cascode amplifier input stage with BJT current mirrors and a class-B output stage in LTspice.
- Analyzed gain, output swing, quiescent power, and harmonic distortion against specified design constraints.
